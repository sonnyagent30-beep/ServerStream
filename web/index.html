Quick Start

  1. Copy your Server URL and Stream Key above
  2. In OBS: Settings → Stream → Service: Custom
  3. Paste the Server URL and Stream Key
  4. Click Start Streaming in OBS
  5. Your stream goes live on all configured platforms
